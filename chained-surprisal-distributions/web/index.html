Entropy & Surprisal Explorer

The surprisal of an event is itself an event. The probability distribution of those surprisal events can be used as another model under which to calculate surprisals of events — chain enough of these together and a fixed point is always found. These are standalone web ports of the original Bokeh apps in this repo; pick a page below.

Discrete

Chained Distributions

Build a chain of histograms, each node's events are the surprisals of the node above it. Explore bin edges, priors, and KL/W1 between neighbors.

 Discrete

Find Fixed Point

Automatically iterate the surprisal-of-surprisal chain to convergence, and see where repeated runs tend to land across bins (simplex, radial, scatter-matrix & parallel-coordinates views).

 Continuous

Chained Distributions

Same chaining idea, but each node fits a smooth density (KDE, adaptive KDE, Gaussian mixture, or B-spline) instead of a histogram.

 Continuous

Find Fixed Point

Continuous-density version of the fixed-point search, with a convergence progression chart and an overlay of every converged density found.
Runs entirely client-side — served with python -m http.server, no backend required.
